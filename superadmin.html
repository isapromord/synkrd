Catálogo Completo de Endpoints RESTful

GET /api/fulfillment/orders

Consulta todas las órdenes confirmadas pendientes de despacho por el almacén.

curl -X GET "https://www.trendyrd.com/api/fulfillment/orders?status=confirmado_whatsapp" \
  -H "x-fulfillment-api-key: ff_live_trendyrd_369_synk"
POST /api/fulfillment/orders/:id/status

El almacén actualiza guía de tracking o estado (en_ruta, entregado, devuelto).

curl -X POST "https://www.trendyrd.com/api/fulfillment/orders/ORD-123/status" \
  -H "x-fulfillment-api-key: ff_live_trendyrd_369_synk" \
  -d '{"status":"en_ruta","tracking_number":"METRO-8849","courier_name":"MetroPac"}'
GET /api/fulfillment/inventory

Obtiene catálogo completo de productos con variantes (talla, color, SKU y stock actual).

curl -X GET "https://www.trendyrd.com/api/fulfillment/inventory" \
  -H "x-fulfillment-api-key: ff_live_trendyrd_369_synk"
POST /api/fulfillment/inventory/sync

El almacén Firebase ajusta existencias reales de variantes o productos en la tienda.

curl -X POST "https://www.trendyrd.com/api/fulfillment/inventory/sync" \
  -H "x-fulfillment-api-key: ff_live_trendyrd_369_synk" \
  -d '{"updates":[{"sku":"POLO-M-BLK","stock":25},{"sku":"POLO-L-WHT","stock":12}]}'

¿Cómo Conectar tu Proyecto de Firebase Studio?

Paso 1: Cloud Function Webhook Crea una función HTTP en Firebase Studio (ej. onOrderDispatched) y pega la URL en la configuración de la tienda. TrendyRD le despachará cada orden confirmada automáticamente.
Paso 2: Sincronización de Stock Configura un Cron Job o trigger de Firestore en Firebase Studio para que cada vez que cambie el inventario físico en el almacén, envíe un POST /api/fulfillment/inventory/sync.
Paso 3: Notificación de Despacho Cuando el chofer o courier recoja el paquete, Firebase llama a POST /api/fulfillment/orders/:id/status con el número de guía para que el cliente reciba su tracking.
